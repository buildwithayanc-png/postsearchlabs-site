# PostSearchLabs website

Static site: `index.html` (home), `local.html` (local practices), `startups.html` (startups), shared `styles.css` and `site.js`.

## Adding the videos
Open `site.js` and paste a link for each page inside `VIDEOS` (YouTube embed, Vimeo, Loom embed or a direct .mp4 link).

## Booking link
All "Book a call" buttons point to the Cal.com 30-minute event.
